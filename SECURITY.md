# Security policy

## Supported versions

Security and correctness fixes are applied to the latest release and `main`.
Older snapshots are not maintained.

## Reporting a vulnerability

Do not include sensitive exploit details in a public issue. Use GitHub's
private vulnerability reporting for this repository when available. If that
feature is unavailable, contact the maintainer listed in `MANIFEST.yml` and
include the affected version, reproduction steps, and impact.

BBC is an anti-jam mark code, not an encryption or authentication mechanism.
Reports that rely only on treating it as a confidentiality mechanism are
outside the project's security guarantees, but implementation defects and
denial-of-service paths are in scope.
